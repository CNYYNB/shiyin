# 拾音

一个本地音乐播放器，有手机版（Android）和电脑版（Windows）。听的是你自己存的歌，不用登录、没有广告，两边可以在局域网里互传歌曲和歌单。

## 能做什么

- 播放本地歌曲：mp3、flac、wav、m4a、ogg/opus 等，自动读取标签和封面
- 歌词：先找歌曲旁边的 .lrc，再找内嵌歌词，最后在线搜（QQ音乐、酷狗、网易云、LRCLIB），可以调歌词快慢
- 歌名修正：乱码自动修复，「歌手 - 歌名」文件名自动识别，可以联网识别中文歌名和封面，也能手动改
- 歌单、播放队列、排序、深色/浅色主题
- 电脑版有桌面歌词（可锁定，锁定后鼠标悬停解锁，快捷键 Ctrl+Alt+L）
- 手机 ↔ 电脑同步：局域网自动发现，输入 6 位配对码，断点续传
- 整理文件夹：把散落在各处的歌移到拾音文件夹，同名同大小的自动跳过

## 怎么用

### 手机版
1. 安装 APK（自己编译，见下文）。
2. 第一次打开会请求读取音乐的权限，允许后自动扫描手机里的歌。
3. 点歌就能播放；长按或点「⋯」可以加入歌单、改歌名、找歌词。

### 电脑版
1. 运行 `拾音-Setup-版本号.exe` 安装，装在当前用户目录，不需要管理员权限。
2. 第一次打开选择音乐文件夹，等扫描完成。
3. 需要 Windows 10/11 和 WebView2（Win11 自带；没有的话安装程序会提示）。

### 手机和电脑互传
1. 手机和电脑连同一个 Wi-Fi。
2. 电脑版点「从手机导入」，手机版打开同步页面，选中电脑，输入电脑上显示的 6 位码。
3. 选歌开始传，传到一半断了重新连上会接着传。

## 遇到问题怎么办

| 情况 | 处理 |
|---|---|
| 同一个 Wi-Fi 却找不到对方 | 多半是路由器开了「AP 隔离」。最稳的办法：手机开热点、电脑连手机热点（关掉手机移动数据就不耗流量）。电脑版「从手机导入」里有「网络诊断」，会告诉你卡在哪一步 |
| 连上了但传输很慢 | 走电脑热点时会限速约 6 MB/s（防止部分 Intel 网卡卡死），换成手机热点或同一路由器即可 |
| 开电脑热点后电脑断网 / 代理失效 | 设置 → 手机 → 「网络修复」 |
| 找不到歌词 | 把同名 .lrc 放在歌曲旁边最准；在线搜不到时可以在歌词面板手动搜索 |
| 歌名是乱码或英文 | 歌曲菜单里「联网识别」或手动改名；改错了可以「撤销自动识别」 |
| 封面不对 | 歌曲菜单里换封面（本地图片或网址），或设置里「清除封面缓存」 |
| 电脑版打不开 / 白屏 | 安装或修复 Microsoft Edge WebView2 Runtime |
| 桌面歌词点不动 | 它被锁定了：鼠标停在歌词上会出现解锁按钮，或按 Ctrl+Alt+L |
| 联网功能失败 | 电脑版会先用系统代理，代理挂了会自动改直连；检查代理软件是否正常 |

## 自己编译

- **手机版** `手机版/`：Android Studio 或 `gradle :app:assembleRelease`。
  签名密钥不在仓库里，请自己生成 keystore，放到 `手机版/keystore/`，并修改 `app/build.gradle.kts` 里的签名配置。以后升级必须一直用同一个密钥，否则手机无法覆盖安装。
- **电脑版** `电脑版/`：需要 Go 和 NSIS，运行 `bash build.sh`，产物在 `dist/`。`build.sh` 里的工具路径按你自己的环境改。
- **自动更新**（可选）：默认地址是占位的 `https://shiyin.example.com`。手机版用 `gradle -PupdateBaseUrl=https://你的地址`，电脑版改 `电脑版/update.go` 里的 `defaultUpdateBase`。更新只在「设置 → 检查更新」里手动触发。不需要的话不用管，播放和同步都不依赖服务器。

更多实现细节在 `手机版/开发笔记.md`、`电脑版/开发笔记.md`、`同步协议.md`（开发记录，里面的路径是作者自己的环境）。
