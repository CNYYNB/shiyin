# 拾音 电脑版 (Windows) v0.3.0

Go + go-webview2 window; UI = embedded HTML/JS/CSS (web/) served from a 127.0.0.1 HTTP server inside the exe
(port 18530–18539, per-launch token → SameSite=Strict cookie, so other web pages cannot call the API).

## Build (on this Linux sandbox, aarch64)
    ./build.sh        # go-winres → GOOS=windows go build -H windowsgui → makensis
Outputs: dist/Shiyin.exe (app), dist/拾音-Setup-<version>.exe (NSIS per-user installer). Version comes from `appVersion` in main.go; also bump winres/winres.json.
Toolchain: /workspace/tools/go (Go 1.23 bootstraps go1.26 toolchain via go.mod), go-winres in /workspace/tools/gopath/bin, apt `nsis` (not persistent: `sudo apt-get install -y nsis`).

## Layout
- main.go — startup, single instance, first-run scan
- server.go — HTTP API (/api/library, /media with Range, /api/cover, /api/lyrics, /api/meta, /api/playlists, /api/state, /api/config, /api/fs, /api/phone/*)
- scan.go — library scan (dhowden/tag, GBK-mojibake repair, "Artist - Title" fallback), display = tags < phone meta < user edits
- duration.go — pure-Go duration probe (mp3 Xing/VBRI/CBR, flac, wav, m4a mvhd, ADTS, ogg/opus)
- lyrics.go — .lrc beside song → embedded → cache → online QQ音乐 → 酷狗 → 网易云 → LRCLIB (port of the phone's Lyrics.kt)
- phone.go — LAN sync client (UDP discovery 18521, pairing code, 2 parallel downloads, 3 attempts, .part + Range resume, 30 s idle timeout, 90 s library timeout, " (n)" on name clash, .lrc beside, covers + Chinese names to meta.json, playlists merged by key)
- reverse.go — 0.2.1「手机连电脑」: while the import dialog polls /api/phone/reverse/{start,status}, listens on TCP 18522 + UDP 18523 (SHIYIN_FIND_PC), 6-digit code, handshake → pool of phone-opened connections (10 s blank-line keep-alive), `reverseClient` dials from the pool (DisableKeepAlives, retry ×3); closes 20 s after the last heartbeat unless importing. lanIPs() skips TUN/virtual adapters (198.18/15, 169.254/16, 100.64/10, names like vpn/tun/clash/meta/vEthernet). lanDial(): direct LAN dialing (no proxy) bound to the adapter on the phone's subnet.
- usbdata.go — 0.2.1 USB fallback: scan collects every 拾音数据.json under the library folders and merges it (meta.Phone names, .拾音封面 covers → covers/phone_<hash>.jpg, playlists by key); prefs.json usbData = {path: sha256} keeps it idempotent; ScanStatus.usb → toast
- platform_windows.go — WebView2 window (title 拾音, icon #1, DPI-scaled size, remembers placement in window.json), named-mutex single instance + focus, explorer /select
- online.go — internet transport (env proxy → Windows system proxy from Internet Settings → direct; falls back to direct if the proxy is down), friendly Chinese network errors, iTunes HK/TW Chinese-name lookup (port of Online.kt; 3.2 s gap, 429 back-off)
- meta.go — display-name edits (manual/online src, 同步到同歌手同专辑 spread, tried), custom covers (file / URL, whole album), 撤销自动识别, 清除封面缓存
- organize.go — 整理到拾音文件夹 (move songs + same-name .lrc from extra folders into the main folder, same size = duplicate skipped, " (n)" on clash, copy+delete across drives)
- update.go — 内置更新: <base>/pc-version.json {version,setup,size,sha256,notes}; download to %TEMP%\ShiyinUpdate with Range resume + 4 attempts + 30 s idle timeout, size + SHA-256 check, run installer /S and quit. Launch check at most once a day (prefs.json updateCheck).
- installer/shiyin.nsi — per-user install to %LOCALAPPDATA%\Programs\拾音, shortcuts, HKCU uninstall entry, WebView2 check, closes running copy
- Data: %APPDATA%\拾音 (config.json [theme dark|light|system, autoOrganize], prefs.json [sort, lyricOffsets, coverEpoch, updateCheck, updPrompt], library.json, meta.json, playlists.json, state.json, window.json, covers/, lyrics/, webview2/, log.txt)

## Key (must match phone)
key = lowercase(fileName without extension, trailing " (n)" removed, trimmed) + "|" + size

## Silent upgrade
`拾音-Setup-x.exe /S`: no dialogs; if 拾音 was installed before (HKCU\Software\Shiyin InstallDir), it closes the running app, upgrades in place, keeps settings (%APPDATA%) and shortcuts (desktop shortcut only re-created if it still exists) and relaunches 拾音.

## Publish (done by the agent that owns deploy)
copy dist/拾音-Setup-X.exe → myplayer-apk/publish/site/shiyin-pc-setup-X.exe and write publish/site/pc-version.json with size + sha256, then publish/deploy.sh.

## Test-only env vars
SHIYIN_REVERSE_PORT / SHIYIN_REVERSE_UDP (reverse listener ports), SHIYIN_UPDATE_URL (update base), SHIYIN_ITUNES_URL (iTunes base; also drops the rate-limit gap), SHIYIN_LRCLIB_URL, SHIYIN_NO_CN_LYRICS=1 (skip QQ/酷狗/网易云), SHIYIN_TEST_INSTALL_CMD (non-Windows stand-in for the installer).

## 0.2.3 — AP 隔离引导 + 电脑热点安全
- Real-world incident (2026-11-20): router (ChinaNet 光猫 192.168.0.1) isolates Wi-Fi clients → user used 「电脑热点」 → PC hard-froze during the transfer (Intel AX201 Netwtw14 event 6062 loop → Kernel-Power 41), a Clash TUN adapter was up; after reboot every proxy timed out until 本地连接* was disabled + `netsh winsock reset` + `netsh int ip reset` + reboot.
- 从手机导入 dialog: 「同一个 Wi-Fi 还是连不上？多半是路由器开了 AP 隔离，按这个顺序试」 ① 手机开热点、电脑连手机热点（推荐，不耗流量，建议关移动数据）② 数据线拷贝 Music/拾音 ③ 关闭路由器 AP 隔离（shows the real gateway via LanIP.gwIp）④ 电脑开热点（不推荐，死机警告; the hotspot button lives here now). Connect failure → banner + automatic 网络诊断; `/api/phone/diag` returns `isolation` (diagIsolation(), pure) → 「诊断结果：路由器开了 AP 隔离」.
- hotspot_guard.go: POST /api/phone/hotspot?on=1 first lists active TUN/VPN adapters (tunLike(): tun/tunnel/wintun/tap/clash/mihomo/meta/wireguard/wg*/sing-box/v2ray/xray/nekoray/hysteria/vpn, or a 198.18/15 address) → `needConfirm` + `tunWarn` → UI warning 「先关掉代理的 TUN 模式」 (仍然开启 → `&force=1`). A hotspot started by 拾音 is recorded in prefs.json `hotspotOwned {on,since}`; hotspotWatch (10 s tick, hotspotShouldOff() pure) turns it off 60 s after the import finished or after 30 min unused; main() turns it off after the window closes; hotspotRecover() turns it off on the next start after a crash. A hotspot the user had already turned on is never turned off.
- Imports whose peer is on the PC hotspot (viaPCHotspot(): 192.168.137.0/24 or the hotspot adapter) run 1 at a time at ~6 MB/s (rateLimiter); ImportJob.slow → progress text 「经电脑热点传输，已限速约 6 MB/s」.
- 设置 → 手机 → 「网络修复」 (also 「电脑断网/代理失效？」 in the dialog, and appended to the diag report on isolation).
- 全屏播放页 fix: `#player` had an implicit auto grid row; the lyrics column's automatic minimum size counted every lyric line, so with long lyrics the row grew to ~3000 px and the centred cover / current line sat far below the window behind the player bar. Now `grid-template-rows: minmax(0, 1fr)` + `min-height: 0` on both columns and the lyrics box; cover = min(420px, 32vw, 100vh − bar − 260px).
- Tests: `go test .` (+ TestTunLike, TestHotspotShouldOff, TestViaPCHotspot, TestRateLimiter, TestHotspotOwnedFlag; TestDiagVerdict checks the order), e2e_v21.py 31 checks (new: guide order), e2e_v2.py 89 checks (version checks now read appVersion from main.go).

- Global hotkey Ctrl+Alt+L: RegisterHotKey (MOD_CONTROL|MOD_ALT|MOD_NOREPEAT) on a hidden message-only window of the desk class created at startup; WM_HOTKEY → deskToggleLock() (only while 桌面歌词 is on). ## 0.3.0 — 给「驿」的正在播放接口 (np.go)
- Why: WebView2 registers 拾音's media session in Windows SMTC under the Microsoft Edge identity, so 驿 (PC remote) merged 拾音 and Edge browser tabs into one 「Edge」 chip and SMTC commands could hit the wrong one. 驿 ≥ 1.0.6 asks 拾音 directly.
- `GET /api/np` → `{app:"shiyin", version, ready, title, artist, album, playing, pos, dur, at}` (pos/dur in s; pos extrapolated while playing; ready=false until the main window reported once).
- `POST /api/np/ctl?do=toggle|play|pause|next|prev` → `{ok:true,n}`; queued on the 桌面歌词 command queue the main page already long-polls (runDeskCmd now also knows play/pause) → runs within ~ms.
- Both need no token but are local-program-only (npLocalOnly): loopback RemoteAddr, Host 127.0.0.1/localhost/::1 (no DNS rebinding), no `Origin` header and no cross-site `Sec-Fetch-Site` (browser pages refused). Anything else → 403.
- The page pushes its state with token-auth `POST /api/np/now` {title,artist,album,playing,pos,dur,rate} on every player event (npPush() in deskPush(), plus every 15 s while playing), whether 桌面歌词 is on or not.
- Port discovery: `%LOCALAPPDATA%\Shiyin\np-port.txt` (decimal port, rewritten each launch; `SHIYIN_NP_DIR` overrides for tests). `%APPDATA%\拾音\port.txt` is still written. Server port is still 18530–18539 (first free).
- Tests: `go test .` (+ TestNPNow, TestNPLocalOnly, TestNPAPI, TestNPPortFile), test/e2e_v30.py — 18 checks (run_e2e.sh sets SHIYIN_NP_DIR=/tmp/shiyin-np). Playwright needs `LD_LIBRARY_PATH=/tmp/libs/root/usr/lib/aarch64-linux-gnu` on this sandbox.
